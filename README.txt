COUNTER-КОЧ 3D — v4

ЗАПУСК
 Windows: двойной клик по start.bat (откроется игра в браузере, окно консоли не закрывать)
 Mac/Linux: start.command
 Можно открыть index.html напрямую, но тогда браузер не даст игре прочитать ggg.png/ccc.png
 из папки — их можно выбрать кнопками в меню или перетащить в окно игры.
 Прогресс (деньги, уровень, покупки) сохраняется в браузере (localStorage).

УПРАВЛЕНИЕ
 WASD — ходьба, Shift — бег, Пробел — прыжок, C / Ctrl — присесть
 C на бегу (Shift+W) — подкат/скольжение
 ЛКМ — огонь, ПКМ — прицеливание (AWP: 2 кратности; нож: сильный удар)
 R — перезарядка, F — осмотр оружия, L — фонарик, H — аптечка, Q/E — наклон
 1-4 / колесо — оружие, M — музыка, Esc — пауза
 В прицеле (ПКМ) включается размытие глубины резкости: в фокусе то, куда целишься.
 Разброс: от бедра большой, в прицеле меньше, присед + прицел — минимальный.
 Попадания: ноги — мало урона, тело — нормально, голова — максимум.

МАТЧ (5:00, 4 волны) — цель выжить. Сложность растёт плавно внутри каждой волны.
 Волна 1 (0:00) — слабые, много лута, под конец появляются первые агрессивные
 Волна 2 (1:00) — крепче, быстрее, доля агрессивных растёт
 Волна 3 (2:15) — только агрессивные, ближе к концу — первые танки
 Волна 4 (3:35) — танки: огромное HP, медленные, много, спавн растёт, лута нет
 Противники обходят препятствия и запрыгивают на ящики за тобой.

=== МУЛЬТИПЛЕЕР (бесплатно, v5) ===
Режимы: КООП · ВОЛНЫ, КООП · DM (вдвоём против ботов), DM 1 НА 1 (5 минут).
1) У обоих должен быть этот же index.html (открыть файл или выложить на бесплатный хостинг: Netlify Drop, GitHub Pages, itch.io).
2) Хост: МУЛЬТИПЛЕЕР -> СОЗДАТЬ -> продиктовать 5-значный код.
3) Друг: МУЛЬТИПЛЕЕР -> ввести код -> ВОЙТИ.
4) Хост выбирает режим и жмёт НАЧАТЬ МАТЧ. Друг кликает по экрану (или ПРОДОЛЖИТЬ), чтобы захватить мышь.
Игра идёт напрямую между компьютерами (WebRTC). Бесплатный сервер PeerJS нужен только на пару секунд, чтобы найти друг друга.
Если сервер комнат недоступен — раздел «Обмен кодами вручную»: обмен двумя текстовыми кодами через Telegram/Discord, вообще без сервера.
Если соединение не устанавливается (строгий NAT у провайдера) — попробуйте другую сеть / раздачу с телефона или впишите TURN-сервер
(например, бесплатный тариф Metered.ca) в формате turn:адрес:порт|логин|пароль.
